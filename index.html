오르GO v0.8.3
계단만 있으면 어디든 산이 된다.
오르GO는 계단운동을 기록하고, 내가 오른 높이를 실제 산을 오르는 과정처럼 보여주는 계단운동 앱입니다.
  1. 클라이머 정보 등록 — 이름 또는 닉네임과 기본 정보를 저장합니다.
  2. 운동할 건물 등록 — 소재지, 사진, 층수와 계단 정보를 등록합니다.
  3. 운동할 건물 선택 — 운동 화면에서 오늘 오를 건물을 고릅니다.
  4. 운동 시작 — 운동 시작을 누르면 시간이 기록됩니다.
  5. 정상 도착마다 +1 — 정상에 도착할 때마다 +1을 누릅니다.
  6. 운동 종료 — 운동을 마치면 종료를 누릅니다.
  7. 기록 확인 — 누적 운동기록, 날짜별 기록과 내가 오른 산을 확인합니다.
